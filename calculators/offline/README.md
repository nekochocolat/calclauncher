# Official NumWorks offline emulators

These unmodified, single-file HTML emulators were downloaded from NumWorks' official offline-download links:

- Graphing, version 26.3.0: https://my.numworks.com/web_simulators/calculator-graphing.zip
- Scientific, version 4.1.0: https://my.numworks.com/web_simulators/calculator-scientific.zip

They are included locally so the two NumWorks calculators can run without a network connection. NumWorks retains all rights to its emulator and trademarks. Check the official download pages for updated versions and applicable terms.
